# HT-CN 数据规范 v0.1

本规范定义 Provider 适配层向 HT-CN Core 暴露的稳定数据口径。任何第三方数据源都必须先转换到本规范，Core 不得直接依赖第三方字段名或单位。

## 个股日线标准字段

| 字段 | 含义 | 统一单位 |
|---|---|---|
| instrument_id | HT-CN 证券唯一标识，例如 `SSE.688256` | - |
| trade_date | 交易日 | 日期 |
| open | 开盘价 | 人民币元 |
| high | 最高价 | 人民币元 |
| low | 最低价 | 人民币元 |
| close | 收盘价 | 人民币元 |
| volume | 成交量 | **股** |
| amount | 成交额 | **人民币元** |
| pre_close | 前收盘价 | 人民币元 |
| pct_change | 涨跌幅 | % |
| turnover | 换手率 | % |
| source | 实际数据源 | - |

## 原始价格与复权

M1 默认落库原始不复权 OHLC。后续复权层必须与原始行情分离，禁止只保存前复权价格而丢失原始行情。

## Provider 单位转换

### AKShare `stock_zh_a_hist`

- OHLC：元
- 成交量：上游文档口径为“手”，进入 HT-CN 前 ×100 转换为“股”
- 成交额：元
- 涨跌幅/换手率：%

### BaoStock `query_history_k_data_plus`

- OHLC：元
- 成交量：股，无需缩放
- 成交额：元
- 涨跌幅/换手率：%
- `adjustflag=3`：不复权

## 原则

1. Core 只读取标准字段。
2. 数据源差异必须在 Adapter 层消化。
3. 所有数量单位转换必须有自动测试。
4. 数据源切换不能改变同一字段的业务含义。
5. 原始数据与衍生/复权数据分层保存。
